# Scalar operator factorization and Kovacic analysis

For a normalized homogeneous second-order equation

```text
y'' + p(x)*y' + q(x)*y = 0,
```

`factor_differential_operator()` searches for exact rational logarithmic derivatives `w = y'/y`. Each such Riccati solution gives a noncommutative factorization

```text
D**2 + p*D + q = (D + a)(D + b),
```

with `w = -b`. `FirstOrderFactorization.verify()` checks both coefficient identities, including the derivative term generated by noncommutative operator multiplication.

`kovacic_analysis()` reduces the equation to normal form `u'' = r(x)u` and runs Kovacic Cases 1--3. Case 1 reuses exact rational Riccati factorization. Case 2 stores the auxiliary polynomial together with explicit quadratic-algebraic logarithmic derivatives. Case 3 stores the full polynomial recurrence and the algebraic equation satisfied by the logarithmic derivative, so degrees 6 and 12 do not need to be expressed artificially in radicals.

```python
import sympy as sp
from odeanalysis import kovacic_analysis

x = sp.symbols("x")
y = sp.Function("y")
result = kovacic_analysis(sp.diff(y(x), x, 2) - y(x), y, x)
assert result.case == 1
assert result.is_liouvillian is True
assert result.verify()
```

If Cases 1, 2, and 3 all fail, `KovacicOutcome.NO_LIOUVILLIAN_SOLUTION` is a negative Liouvillian certificate. `verify()` replays the stored normal-form and case-specific identities.
